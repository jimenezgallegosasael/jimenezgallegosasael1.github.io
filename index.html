Ciberseguridad

Aprende los conceptos fundamentales de la ciberseguridad, conoce las principales amenazas digitales y descubre algunas prácticas para proteger tu información.

¿Qué es la Ciberseguridad?

Protección de sistemas, redes, dispositivos e información.

🔐

Seguridad de la información

Busca proteger la información frente a accesos, modificaciones o pérdidas no autorizadas.

🌐

Seguridad de redes

Protege las redes y las comunicaciones contra accesos y actividades no autorizadas.

💻

Seguridad informática

Incluye medidas para proteger computadoras, sistemas operativos y aplicaciones.

☁️

Seguridad en la nube

Protege los datos y servicios utilizados mediante plataformas de computación en la nube.

Principales amenazas

Conocerlas ayuda a identificar posibles riesgos.

🎣

Phishing

Mensajes o páginas falsas que intentan engañar al usuario para obtener información.

🦠

Malware

Software diseñado para realizar acciones perjudiciales o no autorizadas.

🔑

Contraseñas

Las contraseñas débiles o reutilizadas pueden facilitar el acceso no autorizado a cuentas.

⚠️

Ingeniería social

Técnicas de manipulación utilizadas para conseguir información o provocar determinadas acciones.

Consejos de seguridad

Buenas prácticas para proteger tus cuentas y dispositivos.

  • 🔒 Utiliza contraseñas largas y diferentes para cada cuenta.
  • 🔐 Activa la autenticación de dos factores cuando sea posible.
  • 📱 Mantén actualizado tu sistema operativo y tus aplicaciones.
  • 🎣 No abras enlaces sospechosos.
  • 📧 Verifica los remitentes de correos y mensajes.
  • 💾 Realiza copias de seguridad de información importante.
  • 🌐 Comprueba que los sitios web sean legítimos antes de proporcionar información.
